Build a simple moving-average crossover in Python

This tutorial shows a minimal example using pandas to compute moving averages and generate signals.

import pandas as pd

def sma_cross(prices, short=10, long=30):
    short_sma = prices.rolling(short).mean()
    long_sma = prices.rolling(long).mean()
    signal = (short_sma > long_sma).astype(int).diff()
    return signal

Use this as a starting point. Backtest with proper out-of-sample testing and include transaction costs.
