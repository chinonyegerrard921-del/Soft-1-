# Soft Trading Skill — Static site for GitHub Pages

This repository contains a ready-to-publish static website for "Soft Trading Skill" (trading, tutorials, and code).

How to publish on GitHub Pages (recommended: project site)

1. Files are already in the repository root. To publish the site from this repo:
   - Go to the repository on GitHub: https://github.com/chinonyegerrard921-del/Soft-1-
   - Settings → Pages (or Settings → Code and automation → Pages)
   - Under Build and deployment / Source choose the branch "main" and folder: "/ (root)"
   - Save. GitHub will publish the site; the URL will be:
     `https://chinonyegerrard921-del.github.io/Soft-1-/`

2. Wait a minute or two for the site to appear. If nothing shows, confirm index.html is at the repository root.
